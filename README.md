# CLMI OPTION 2 — Stratos (navy / bleu électrique / cyan)

Create a professional industrial website homepage for CLM Industry, 
a French company specializing in industrial gas measurement campaigns.

## DESIGN SYSTEM — Option 1 : Dark Industrial (Stratos)
- Background: deep navy #1A2E44
- Primary accent: electric blue #1E5FA8
- Secondary accent: cyan #2196B6
- Text on dark: white #FFFFFF
- Text secondary: light gray #D0D5DD
- Card backgrounds: #223550 (slightly lighter than bg)
- Font: Inter or IBM Plex Sans
- Style: dark, technical, data-driven, no gradients, flat surfaces
- Border radius: 8px for cards, 4px for buttons
- CTA buttons: cyan background #2196B6, white text, no border radius > 6px
